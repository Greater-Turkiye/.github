## Türkçe

| Ne istiyorsunuz? | Nereye? |
|---|---|
| Genel soru, yöntem tartışması, fikir | [Tartışmalar](https://github.com/orgs/Greater-Turkiye/discussions) |
| Bir olay veya kayıt önermek | [datasets — "Veri önerisi" formu](https://github.com/Greater-Turkiye/datasets/issues/new/choose) |
| Yeni kaynak önermek | [datasets — "Kaynak önerisi" formu](https://github.com/Greater-Turkiye/datasets/issues/new/choose) |
| Bir kayıttaki hatayı bildirmek | [datasets — "Düzeltme" formu](https://github.com/Greater-Turkiye/datasets/issues/new/choose) |
| Sözlüğe (bölge, olay türü vb.) ekleme önermek | [datasets — "Sözlük önerisi" formu](https://github.com/Greater-Turkiye/datasets/issues/new/choose) |
| Araç veya platform hatası, özellik isteği | İlgili depoda "Hata / özellik" formu |
| El kitabında hata veya çeviri | [handbook](https://github.com/Greater-Turkiye/handbook) deposunda PR |
| Nasıl katkı verileceği | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Roller, terfi, kararlar | [GOVERNANCE.md](GOVERNANCE.md) |
| **Hassas içerik, kaldırma talebi, güvenlik açığı, davranış bildirimi** | **Yalnızca özel kanal:** [SECURITY.md](SECURITY.md) |

Gönüllü bir topluluğuz; yanıtlar birkaç gün sürebilir. Lütfen aynı soruyu birden çok yerde açmayın. Üyelere doğrudan özel mesajla destek talebinde bulunmayın.

## English

| What do you need? | Where |
|---|---|
| General question, methodology discussion, ideas | [Discussions](https://github.com/orgs/Greater-Turkiye/discussions) |
| Propose an event or record | [datasets — "Data submission" form](https://github.com/Greater-Turkiye/datasets/issues/new/choose) |
| Suggest a new source | [datasets — "Source suggestion" form](https://github.com/Greater-Turkiye/datasets/issues/new/choose) |
| Report an error in a record | [datasets — "Correction" form](https://github.com/Greater-Turkiye/datasets/issues/new/choose) |
| Propose a vocabulary addition (region, event type, etc.) | [datasets — "Vocabulary proposal" form](https://github.com/Greater-Turkiye/datasets/issues/new/choose) |
| Tool or platform bug, feature request | "Bug / feature" form in the relevant repository |
| Handbook error or translation | PR in the [handbook](https://github.com/Greater-Turkiye/handbook) repository |
| How to contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Roles, promotion, decisions | [GOVERNANCE.md](GOVERNANCE.md) |
| **Sensitive content, takedown request, vulnerability, conduct report** | **Private channel only:** [SECURITY.md](SECURITY.md) |

We are a volunteer community; answers may take a few days. Please do not post the same question in several places, and do not ask members for support through direct messages.
